# Deploy Bot 使用介绍 02：登录、仪表盘与双端入口

第一次进入系统时，先把登录入口、仪表盘和两端分工看清楚，后面的配置和部署会顺很多。

## 1. 登录页

进入系统后，先看到的是统一登录页：

![登录页](../screenshots/login.png)

登录成功后，系统会根据当前账号权限进入对应视角：

- 管理员可以在管理端和用户端之间切换
- 普通用户只看到部署工作台需要的入口

## 2. 管理端仪表盘

管理端首页更偏总览，适合先看当前整体情况：

![管理端仪表盘](../screenshots/admin-dashboard.png)

这里可以快速看到：

- 项目、模板、流水线、部署记录等核心数量
- 近 7 天部署趋势
- 最近部署与部署异常
- 服务概况和主机资源

如果你负责平台维护，通常会先从这里看当天整体状态。

## 3. 用户端仪表盘

用户端首页更偏执行视角，只保留部署者真正关心的信息：

![用户端仪表盘](../screenshots/user-dashboard.png)

和管理端相比，用户端不会把配置入口堆出来，而是更强调：

- 最近部署
- 当前服务状态
- 自己需要关注的部署异常

## 4. 管理端和用户端怎么切换

管理员右上角会看到两个入口：

- `控制中心`
- `部署工作台`

这两个入口分别对应：

- `控制中心`：维护项目、主机、模板、流水线、系统设置等配置
- `部署工作台`：发起部署、看进度、看历史、排查问题

这样的好处是，配置动作和执行动作被自然分开，不会把所有能力堆在一个页面里。

## 5. 先理解菜单结构，再开始配置

如果是第一次使用，建议先按这个顺序理解页面：

1. 管理端：项目、主机、运行环境、模板、流水线
2. 用户端：流水线大厅、部署记录、部署详情
3. 服务、通知、系统设置作为补充能力

把登录入口和两端职责看清以后，再进入后面的配置章节，会更容易把整套系统串起来。
